The fork server listens on TCP port 5001; the pthread server listens on port 5002. Compile using `gcc fork_server.c -o fork_server` and `gcc pthread_server.c -o pthread_server -pthread`. Run the server, then use `nc 127.0.0.1 5001` or `nc 127.0.0.1 5002` from another terminal and type a message. Each example handles one read per client and is intended for lab demonstration, not production deployment.
